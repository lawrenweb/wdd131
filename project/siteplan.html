Talamaivao Fitness Hub - Website Planning Document

Site Name

Talamaivao Fitness Hub

This site provides fitness resources, workout plans, nutrition advice, and motivation for individuals who want to improve their health and fitness.

Site Purpose

The purpose of this website is to help users learn about fitness, healthy eating, and effective workout routines. Visitors will find beginner-friendly fitness information, exercise plans, and wellness tips.

Scenarios

  • What workout routine should I follow as a beginner?
  • What foods should I eat to support my fitness goals?
  • How often should I exercise each week?
  • Where can I contact the website owner for additional information?

Color Schema

#1D3557

Navy Blue will be used for headings, navigation, and footer areas.

#F1FAEE

Light Gray will be used for page backgrounds and content sections.

#F4A261

Orange will be used for buttons, highlights, and important accents.

Typography

Poppins will be used for page headings and titles.

Arial will be used for body text and paragraphs.
